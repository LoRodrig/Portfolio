## Projetos em destaque

### Prospector CNPJ — Plataforma Local de Prospecção

Projeto de Engenharia de Dados que transforma dados públicos da Receita Federal em uma ferramenta web de prospecção geográfica de empresas.

A versão atual é focada na região de Maringá-PR, contemplando:

* Maringá
* Sarandi
* Paiçandu
* Marialva
* Mandaguari

O projeto foi desenvolvido como uma solução localizada para portfólio, mas com arquitetura preparada para expansão futura para outras cidades e estados.

Principais recursos:

* Extração de dados públicos da Receita Federal
* Tratamento e carga com Python
* Armazenamento em PostgreSQL + PostGIS
* Consulta geoespacial por raio
* Filtro por CNAE
* Mapa interativo com Leaflet.js
* Exportação para CSV
* Automação com GitHub Actions

Tecnologias utilizadas:

* Python
* PostgreSQL
* PostGIS
* Supabase
* GitHub Actions
* JavaScript
* HTML
* CSS
* Leaflet.js
* Chart.js

Links:

* Site: https://lorodrig.github.io/prospector-cnpj/
* Repositório: https://github.com/LoRodrig/prospector-cnpj

## Como executar localmente

Clone este repositório:

```bash
git clone https://github.com/LoRodrig/portfolio.git
```

Acesse a pasta do projeto:

```bash
cd portfolio
```

Abra o arquivo `index.html` no navegador.

Como o projeto é feito apenas com HTML e CSS, não é necessário instalar dependências.

## Publicação

Este portfólio está publicado utilizando GitHub Pages.

Para publicar alterações:

```bash
git add .
git commit -m "Atualiza portfolio"

```

Depois, basta aguardar a atualização automática do GitHub Pages.
