🏨 Predição de Cancelamento de Reservas

Projeto de Ciência de Dados desenvolvido para prever cancelamentos de reservas em hotéis utilizando Machine Learning.

O projeto utiliza análise exploratória, tratamento de dados, engenharia de features e Random Forest para identificar padrões associados ao cancelamento de reservas.

🎯 Objetivo:
Reduzir perdas financeiras e apoiar decisões estratégicas através da previsão de reservas com maior risco de cancelamento.

📈 Resultado:
Modelo com aproximadamente 89% de acurácia.

🛠️ Tecnologias:
Python • Pandas • Scikit-learn • Matplotlib • Seaborn • Jupyter Notebook
